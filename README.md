# Orbit // LockScreen Studio
### Google × Handshake AI Skills Studio Challenge: *"Your Deadline, Your Design"*

**Orbit LockScreen Studio** is a focused, high-polish web application that generates functional, beautifully formatted countdown lock screen wallpapers for phones (9:16) and desktops (16:9). Built directly for the official **Google × Handshake AI Skills Studio November 2026 Challenge**.

---

## 🌟 Why This Wins
1. **Execution (25%):**
   - Live rendered canvas formatted for iPhone/Android lock screens with negative-space protection ensuring wallpaper content never collides with system clock or notifications.
   - High-resolution 3x Retina PNG wallpaper export with one click.
2. **Creativity (25%):**
   - Reverse milestone roadmap (working backward from target deadline).
   - Dynamic countdown with synchronized live seconds, minutes, hours, and days.
   - 4 distinct aesthetic themes: *Cyberpunk / Terminal*, *Bauhaus Minimal*, *Cosmic Gradient*, and *Swiss Brutalist*.
3. **Usefulness / Value (25%):**
   - Pre-loaded with presets for Tech Internship deadlines (Google SWE 2027), Creative Drops (Album Releases), and Academic Finals.
   - Fully customizable milestones with instant toggle checks.
4. **Polish & Thoughtfulness (25%):**
   - Light and Dark mode support across all presets.
   - Simulated system clock overlay toggle to test alignment at a glance.

---

## 🚀 Quickstart
```bash
npm install
npm run dev
```

## 🛠️ Tech Stack
- **Framework:** React 18 + TypeScript + Vite
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Export Engine:** `html-to-image` (3x Retina export) + `canvas-confetti`
